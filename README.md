# MyDailyWork Internship – Machine Learning Projects

## 👩‍💻 Internship Overview

This repository contains the **Machine Learning projects completed as part of my MyDailyWork Internship**.

The projects demonstrate practical implementation of data preprocessing, feature engineering, model training, prediction, and evaluation using **Python and Scikit-learn**.

---

## 📂 Projects

### 🔹 Task 1 – Titanic Survival Prediction

A Machine Learning classification project that predicts whether a passenger survived the Titanic disaster.

**Algorithm:** Random Forest Classifier

**Technologies:**

* Python
* Pandas
* Scikit-learn

📁 **[View Task 1](./Task-1-Titanic-Survival-Prediction/)**

---

### 🔹 Task 2 – Movie Rating Prediction

A Machine Learning regression project that predicts movie ratings using information such as year, duration, votes, genre, director, and actor.

**Algorithm:** Random Forest Regressor

**Technologies:**

* Python
* Pandas
* NumPy
* Scikit-learn

📁 **[View Task 2](./Task-2-Movie-Rating-Prediction/)**

---

### 🔹 Task 3 – Iris Flower Classification

A Machine Learning classification project that predicts the species of an Iris flower based on sepal and petal measurements.

**Algorithm:** K-Nearest Neighbors (KNN)

**Technologies:**

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

📁 **[View Task 3](./Task-3-Iris-Flower-Classification/)**

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/MyDailyWork-Internship.git
```

### 2. Open the Repository

```bash
cd MyDailyWork-Internship
```

### 3. Install Required Libraries

```bash
pip install pandas numpy scikit-learn matplotlib seaborn
```

### 4. Run an Individual Task

For example:

```bash
cd Task-1-Titanic-Survival-Prediction
python main.py
```

For Task 2:

```bash
cd Task-2-Movie-Rating-Prediction
python movie_main.py
```

For Task 3:

```bash
cd Task-3-Iris-Flower-Classification
python main.py
```
